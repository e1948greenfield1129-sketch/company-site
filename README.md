# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「株式会社スカイライン・テクノロジーズ」のコーポレートサイト(サンプル)です。HTMLとCSSのみで構成された単一ページのサイトで、ビルドや外部ライブラリは不要です。

> ※ 掲載している企業名・数値・住所・メールアドレスはすべて架空のものです。

## サイトの概要

業務システム開発、クラウド、AI活用までを一気通貫で支えるソフトウェア開発会社、という設定のサイトです。ページは次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| ヒーロー | キャッチコピーと、相談・事業内容への導線 |
| ABOUT(私たちについて) | 企業理念と実績数値(導入企業数、開発年数など) |
| SERVICES(事業内容) | 受託開発、クラウド・DX支援、AI・データ活用など6つのサービス |
| WORKS(導入事例) | 物流・小売・医療の導入事例 |
| PROCESS | ヒアリングから運用までの流れ |
| COMPANY(会社概要) | 会社名、設立、所在地などの基本情報 |
| CONTACT(お問い合わせ) | メールでの相談窓口 |

### 特徴

- レスポンシブ対応(スマートフォン幅ではナビゲーションを簡略化)
- ライトモード/ダークモードの自動切り替え(OSの設定に追従)
- ヘッダー固定のナビゲーションと、お知らせ(ニュース)のドロップダウン
- スムーズスクロールによるページ内移動

## ブラウザで index.html を開く手順

このサイトはサーバーを必要としません。`index.html` をブラウザで開くだけで表示できます。

### 方法1: ダブルクリックで開く

1. エクスプローラー(Finder)でこのリポジトリのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2: ブラウザにドラッグ&ドロップする

1. Chrome、Edge、Firefox、Safari などのブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ&ドロップします。

### 方法3: アドレスバーからファイルパスを指定する

1. ブラウザのアドレスバーに `file:///` に続けて `index.html` の絶対パスを入力します。
   - 例(Windows): `file:///C:/Users/<ユーザー名>/OneDrive/Desktop/company-site/index.html`
2. Enterキーを押すと表示されます。

### 方法4: コマンドラインから開く

リポジトリのフォルダで次のコマンドを実行します。

```powershell
# Windows (PowerShell)
start index.html
```

```bash
# macOS
open index.html

# Linux
xdg-open index.html
```
